# Lotte tra Amici

Gioco di lotte in stile Pokémon, in un'unica pagina HTML (`index.html`), senza dipendenze esterne.

## Come provarlo

Apri `index.html` nel browser.

## Note

- I progressi (il libretto) sono salvati nel `localStorage` del browser, quindi sono legati alla pagina e al browser in cui giochi.
